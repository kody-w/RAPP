# The Zen of RAPP

```
Simple is better than clever.
If pasting it works, there is nothing to build.
A file you drop beats a feature you learn.
One file, one agent.
The kernel stays still; everything else is a file beside it.
Words over machinery.
If you have to teach the machinery, the machinery is wrong.
Regular people first; experts can always go deeper.
Add nothing a user would have to be told about.
Subtracting is a feature.
Conversation is the interface.
Nothing runs without a yes.
Local first, and yours forever.
The one-liner never breaks.
Every new word must earn its place.
Done means someone used it, not that it shipped.
If it's hard to explain, it's a bad idea.
```

Approved by Kody Wildfeuer, 2026-10-03. Every RAPP and Brainstem decision is held to these lines, by people
and by AI alike.

## As koans

**The skill.** A student asked, "How do I add a skill to the Brainstem?" The master pasted the skill into the
chat and pressed Enter. The student had prepared three questions, and asked none of them.

**The framework.** An engineer built a framework so that anyone could add skills. No one came. The master pasted
a skill into the chat. Everyone came.

**Mu.** A student asked, "Does the kernel need this feature?" The master said, "Mu."

**Beside.** "Master, where does the new feature go?" "Not in the kernel." "Then where?" "In a file beside it."
"And if it needs no file?" The master said nothing, and the student put the keyboard away.

**One word.** "How many words does it take to teach RAPP?" The master held up one file.

## Current protocol status

The main `kody-w/RAPP` repository's current implementation pin is the
structural RAPP/1 rev-5 record in
[`RAPP1_AUTHORITY.json`](https://github.com/kody-w/RAPP/blob/main/RAPP1_AUTHORITY.json),
and its limitations remain explicit in
[`RAPP1_STATUS.md`](https://github.com/kody-w/RAPP/blob/main/RAPP1_STATUS.md).

Canonicalization, identity, frames, wire, eggs, registry, trust, and protocol
evolution defer to that pinned authority until an authorized migration advances
the implementation pin. The public RAPP/1 standard may advance independently.
