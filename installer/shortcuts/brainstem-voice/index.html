Brainstem Voice

The 5-action Apple Shortcut that turns Siri into a brainstem client. "Hey Siri, ask Brainstem…"

🟡 Author phase. The protocol is locked and the infrastructure is in place. The signed .shortcut file lands here once authored on a Mac with Shortcuts.app. Until then, follow the build steps below — it takes 5 minutes. Historical status copy is preserved. No signed file, install link, endpoint call, or credential flow is active; use the local planner below. Installer evidence points to KERNEL_PIN.json and the immutable kody-w/rapp-installer@brainstem-v0.6.9 source tag.

What it does

You say "Hey Siri, ask Brainstem [thing]" (or tap the Shortcut). Siri dictates → POSTs to your brainstem's /chat endpoint → extracts the voice_response field → speaks it aloud. The brainstem already emits a TTS-shaped voice slot for exactly this; the Shortcut is just the harness.

One bundle. Six surfaces. Zero native code.

Build it (5 minutes)

Open Shortcuts.app on macOS or iOS. File → New Shortcut. Name it Brainstem Voice. Add these 5 actions in order:

  1. Ask for Input Prompt: "What do you want to ask?". Input Type: Text. (When triggered from Siri or Watch, this becomes the dictation prompt automatically.)
  2. Get Contents of URL URL: {your_brainstem_url}/chat. Method: POST. Headers: Content-Type: application/json. Request Body: JSON with user_input = Provided Input and conversation_history = empty list. Inert historical action. Do not add or run this network step from the restored page; the local planner builds an exact rev-5 request preview instead.
  3. Get Dictionary Value Get: Value. Key: voice_response. From: Contents of URL. Historical field context only. Current speech derives locally from the exact response string.
  4. If (optional fallback) If Dictionary Value is empty, fetch response instead. (Used when voice mode is off.) No fetch occurs here. The preview below operates only on sample text already in the page.
  5. Speak Text Text: Dictionary Value. Voice: system default. Wait Until Finished: on.

Tap the play button to test. Type or speak something. Confirm the brainstem's voice response is spoken back.

Then sign + ship

The original distribution sequence remains visible as inert source. This page performs none of these actions.
  1. File → Export… → save as brainstem-voice.shortcut.
  2. Sign for public install: bash installer/shortcuts/sign.sh brainstem-voice.shortcut

Why this and not a native app

  
A native watchOS / iOS app would need an Apple Developer Program enrollment ($99/yr), App Store review per release, watchOS-specific code, per-OS-version regression testing. This Shortcut needs none of it. The brainstem already emits the voice slot. The Shortcut is harness, not product.

  
The constitutional posture is captured in   the Surfaces vault note: reach new form factors with web tech and OS-native primitives, not native code.
